Fluxbox2 has changed quite a bit

I've continued working on Fluxbox2 and the tools around it. This new Essora Eos ISO brings those changes together. The idea is still the same: keep the desktop lightweight, easy to use and under the user's control, without turning it into a large desktop environment.

Fluxbox2 is not simply an old Fluxbox release with a different theme. It started from the Fluxbox codebase, but this is an actively developed Essora fork. The version included here is Fluxbox2-Essora 1.7.20, with major changes to appearance, the panel, menu and desktop integration.

One of the biggest changes: Fluxbox2 no longer depends on classic Fluxbox style files for its appearance. Window decorations and native Fluxbox menus now follow the GTK3 theme chosen by the user.

That means the titlebars, window buttons and other decorations can match the rest of the GTK3 desktop. You can choose the theme, icons, cursor and fonts through Essora Appearance instead of looking for a separate Fluxbox theme.

A new panel and a more flexible application menu

Fluxbox2 now includes its own integrated panel. Its engine is based on tint2, but the panel runs inside Fluxbox2 rather than launching a separate tint2 process. It provides the taskbar, launchers, notification area and clock, and it can be configured from Fluxbox2 Settings.

The configuration tool can change panel placement, size, buttons, themes and shortcuts. It also includes a visual panel builder, so you don't need to edit configuration files just to move a launcher or change the panel layout.

A Windows 11-style menu by default — but not the only choice

The default application menu now uses a Windows 11-inspired Start layout, with a search field, favorites, application categories and a small Recommended section. The recommended shortcuts give quick access to the browser, terminal, ROX-Filer2 and Fluxbox2 Settings.

Favorites, Desktop, System and other categories can be browsed without having to scroll through one huge list. The menu also includes an All apps view. And if you don't like the default design, there are several other menu templates to choose from, with options for layout, colors, fonts and favorites.

ROX-Filer2 continues to manage the desktop itself, including wallpaper, file icons, Trash and storage devices. Fluxbox2 handles the windows, panel, menu and session integration.

Desklet and Picom are part of the Fluxbox2 setup

Two other components are now managed directly through the Fluxbox2 configuration: Essora Desklet and the Picom compositor. They're enabled in the desktop setup shown in this ISO, but they are both optional. If either one causes trouble on your hardware, you can disable it from Fluxbox2 Settings.

Essora DeskletClock, date and other configurable desktop information. Presets and display settings can be changed from the same configuration window.
PicomOptional rounded corners, subtle transparency, shadows and VSync. Its settings are kept with the Fluxbox2 configuration.

Picom is controlled by the Fluxbox2 session, not by an unrelated desktop autostart entry. The aim is to keep the effects subtle while leaving users free to switch them off. The Desklet is also supervised by Fluxbox2, so a Desklet problem should not bring down the window manager.

Several Essora applications have been updated too

This release isn't only about Fluxbox2. I've also been working on the applications that come with Essora, with changes to the browser, office tools, editor and software manager.

Essora Browser 159.0

Essora Browser has been updated to 159.0. It remains based on Mozilla's Firefox/Gecko source code, adapted for Essora, with its own branding and desktop integration.

Essora Office — improvements to Writer and PDF

Essora Office continues to improve, especially in Writer and PDF, two areas I've spent time working on. The suite brings document, spreadsheet, presentation, drawing and PDF tools together in one interface.

Essora Editor — rewritten as a GUI for Neovim

Essora Editor has been rewritten. It is no longer a Geany fork; this is a new graphical interface built for Neovim. The goal is to keep editing code and text straightforward while using Neovim as the editor underneath.

Essora Store — DEB, Flatpak and AppImage together

The software manager has also grown. What previously focused on Debian packages now offers three formats in the same application: DEB through APT/dpkg, Flatpak and AppImage. Each one has its own tab, with package listings and actions appropriate to that format.

This lets users browse traditional system packages alongside Flatpak applications and an AppImage catalog without moving between several unrelated interfaces.

Essora VM — a graphical frontend for QEMU

Essora VM provides a graphical frontend for QEMU. It is intended to make creating and managing virtual machines more approachable, including keeping multiple virtual machines in one place. It's useful for testing other systems without installing them directly on your computer.

MagDock — a helpful screen magnifier

I've also included MagDock for users who find small text or interface elements difficult to read. It provides screen magnification without requiring a particular desktop environment or window manager.

MagDock was created by JakeSFR from the Puppy Linux community, inspired by the magnifier included with Windows XP. Credit for the original tool belongs to JakeSFR. You can read more about it in the Puppy Linux forum discussion and the original MagDock 1.3 post.

Still lightweight, with more of the desktop working together

Fluxbox2 continues to be about a small and manageable desktop. The difference in this release is how much more of it now works together: GTK3 appearance, an integrated panel, a configurable menu, optional visual effects, the Desklet and the applications around them.

There is still work to do, and not every feature will be useful on every computer. That's why keeping the configuration accessible — including the option to turn things off — matters just as much as adding new features.
